# **App Name**: TaskWise

## Core Features:

- Task Logging: Log completed tasks with details such as task name, description, and attachments.
- Timestamping: Automatically record the date and time when a task is marked as completed.
- Zone Assignment: Assign tasks to specific zones within the house (e.g., kitchen, living room, garden).
- Person Assignment: Assign tasks to the person who completed them.
- Task Reporting: Provide simple reports and visualizations on the tasks that have been performed, for example which tasks are performed most, and by whom.

## Style Guidelines:

- Primary color: Soft blue (#77B5FE) to evoke a sense of calm and organization.
- Background color: Light, desaturated blue (#EAF2FF) for a clean and unobtrusive backdrop.
- Accent color: Muted purple (#B19CD9) to provide a subtle highlight to interactive elements.
- Body and headline font: 'PT Sans' for readability and a modern, slightly warm feel.
- Use simple, clear icons to represent different zones and task categories.
- Employ a clean and structured layout to facilitate easy navigation and task management. Leverage the Bulma CSS framework for a responsive and modular design.
- Use subtle transitions and animations to provide feedback on user interactions, like task completion.
